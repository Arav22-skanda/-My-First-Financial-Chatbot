Financial Chatbot – Documentation
1.Overview:

This is a simple rule-based chatbot built in Python that answers common financial questions using predefined responses. It is designed to help users retrieve basic financial information such as revenue, expenses, and net income from previously analyzed data.

2.How It Works:

The chatbot uses if-else conditions to match the user's input with a set of predefined financial queries.

When the user types an exact question, the chatbot returns a fixed answer based on your financial data.

If the input doesn't match any of the predefined questions, the chatbot displays a default message.

3.Supported Queries:

This chatbot currently supports five financial queries:

What is the total revenue?
➜ The total revenue is $1.5 million.

How has net income changed over the last year?
➜ Net income increased by $200,000 compared to last year.

What are the total expenses?
➜ Total expenses are $1.1 million.

What is the profit margin?
➜ The profit margin is 26.7%.

How much cash does the company have?
➜ The company has $500,000 in cash.

4.Technologies Used:

Python 3.13.7

Standard Python input() and print() functions

Optional: Can be extended using Flask for web-based interaction

5.Testing:

The chatbot is run from the command line using python Mychatbot.py.

It was tested with the supported queries above to confirm correct responses.

Invalid or unknown questions return:
"Sorry, I can only provide information on predefined queries."

6.Limitations:

Only responds to exact predefined queries.

Cannot interpret variations or natural language (e.g., “How much did we earn?” will not match).

Static data — not connected to a live financial system or database.

No real-time data updates.
